# Contributing to Simple Interest Calculator
Thank you for considering contributing to our micro-finance simple interest calculator tool!

## How to contribute
1. **Fork the repository: ** Create your own copy of the project.
2. **Create a Feature Branch: ** `git checkout -b feature/your-feature-name`
3. **Commit your changes: ** Keep commit message clear and concise.
4. **Push to your Branch: ** `git push origin feature/your-feature-name`
5. **Open a Pull Request:** Describe your updates and submit it for review.

 ## Code Style & Standards
 * Keep scripts clean and documented
 * Verify calculations accuracy before opening a pull request.
